# AFL Trade Machine v6.4

Independent AFL trade, draft and Best 23 simulator.

## V6.4
- Best 23 position containers now visually blend into the AFL field instead of carrying club stripes.
- The actual player selector/name control carries the club colour treatment, while the club dropdown remains neutral.
- Club selector/badge accent patterns refined, including Richmond black/yellow/black, West Coast dark-yellow/blue/dark-yellow, Carlton navy, Western Bulldogs red/white/blue and GWS orange/dark-blue/orange.
- Added an explicit RUN TRADE button and Trade Verdict panel.
- Trade Verdict reports indicative fairness, club-by-club value movement, list-size/compliance issues, future-pick warnings, player-consent caveats and known estimated salary movement.
- Preserves V6.3 live-draft club logos, drag/drop interactions, published mock draft, player profiles and Best 23 assumptions/import tools.

Fairness uses indicative player values plus known DVI points and is not an official AFL valuation. AFL approval, player consent, final list categories, salary-cap treatment and special draft/trade rules still require official confirmation.
