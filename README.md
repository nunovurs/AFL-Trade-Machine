# AFL Trade Machine v6

Independent AFL trade, draft and Best 23 simulator.

## V6
- Soft mid-light sports-tool theme with dark header.
- Recognisable AFL club logo references and full-opacity club branding.
- Club-coloured On the Clock panel and Best 23 dropdowns.
- Live draft prospect profiles with bio fields, personal scouting notes and WATCH links.
- MY MOCK DRAFT is a fixed editorial board (not an editor) through Pick 39, including absorbed bid selections.
- Best 23 supports Add Any Player, Import Trade, and Add My Draft Prospect.

Player measurements and photos are reference material and may change as official information is updated. Missing/unverified fields deliberately use a blank or neutral fallback rather than invented data.
