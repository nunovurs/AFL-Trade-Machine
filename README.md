# AFL Trade Machine — v5

Independent AFL list-management simulator with three connected tools.

## Trade Machine
- 2–4 club trades, with 3/4-team layouts kept in columns on desktop
- alphabetical club selector with local high-contrast independent club marks
- full current player lists
- current 2026 owned picks with DVI points
- 2027/2028 future picks
- Incoming + Outgoing shown together for every club
- indicative list-size checks
- contract/salary context where publicly supportable
- trade state can feed incoming players into Best 23

## 2026 Mock Draft
- live current-order simulator
- prospect board and on-the-clock workflow
- live on-clock pick trades
- father-son / Academy / NGA bid prompts
- 2026 two-pick matching limit through Pick 36
- 412-point maximum deficit handling with future-first check
- editable **My Mock Draft** view for the user's own selections and explanations

The most complex surplus-pick and compensation reshuffling remains marked as an approximation rather than presented as exact draft-night accounting.

## Build Your Best 23
- all 18 clubs
- 18 starters + five interchange
- full club player pool
- **Add Player** for trade, draft or custom assumptions
- **Import Trade** to bring incoming traded players from the Trade Machine into that club's squad pool
- **Add Draft Prospect** to test hypothetical draftees
- hypothetical players are visibly tagged on the field
- duplicate prevention, search, reset and copy team

A reserves/VFL/WAFL/SANFL companion-side builder remains a planned expansion.

## Branding
Club marks included in this package are independent, locally stored geometric designs created for this simulator. They are intentionally not official AFL club logos.

## Data notes
Squads are based on current club/AFL list information used for the simulator. Contract and salary information is incomplete by design; salary figures are estimates unless publicly disclosed. Draft order and ownership data are maintained as simulator data without displaying third-party source branding in the product.

This project is independent and is not affiliated with or endorsed by the AFL. Player values are indicative only.
