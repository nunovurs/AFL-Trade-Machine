# AFL Trade Machine — v6

Modes:
- Trade Machine
- Live 2026 Mock Draft
- My Mock Draft (read-only editorial board)
- Best 23 Builder

v6 additions:
- My Mock Draft is the author's published mock, not a second simulator.
- Shared player profiles with scouting description, comparison and club-selection reasoning.
- Live simulator player names open the same profile cards.
- WATCH links search for Footy Stuff player highlights.
- Best 23 can Add Any Player, import incoming trade players, or add prospects from My Draft profiles.
- Best 23 club selector and player dropdowns use the selected club's colours.
- On-the-clock panel uses the current club's colour.
- Club logo source override uses recognisable public logo artwork rather than generated shield placeholders.

Notes:
- Player weight is shown only where a reliable figure has been entered; otherwise it displays —.
- The player profile image slot deliberately falls back to a neutral initials panel when a verified direct image has not yet been added, rather than showing the wrong person.
- Mock-draft bid reshuffling remains an MVP approximation for the AFL's most complex compensation/surplus-pick cases.
